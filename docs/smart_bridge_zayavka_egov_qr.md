Сведения об информационной системе:
- наименование: Портал электронного документооборота EDO.ANESCOM;
- адрес: https://edo.anescom.kz;
- владелец: ТОО «ANESCOM/АНЕСКОМ»;
- пользователи: работники и руководители ТОО «ANESCOM/АНЕСКОМ» и ТОО «AVTOCOMP/АВТОКОМП», контрагенты;
- способ подписания: QR-подписание и кросс-подписание (переход из браузера мобильного телефона в eGov mobile);
- формат подписи: CMS с вложенными данными (CMS_WITH_DATA), документы в формате PDF;
- аутентификация при получении документов: Token (одноразовые ссылки с ограниченным сроком действия);
- проверка подписи: по Правилам проверки подлинности ЭЦП (проверка цепочки сертификатов НУЦ РК и статуса отзыва OCSP);
- ожидаемый объём: до 1 000 документов в месяц.

## Порядок подачи (делает пользователь своей ЭЦП)
1. Войти на sb.egov.kz ЭЦП руководителя (или сотрудника с правом подписи) ТОО «ANESCOM/АНЕСКОМ», зарегистрировать организацию, если ещё не зарегистрирована.
2. В каталоге сервисов найти сервис QR-подписания / подписания через eGov mobile, открыть «Подать заявку».
3. Заполнить поля по таблице выше, приложить письмо (PDF, подписанное), подписать заявку ЭЦП.
4. Номер заявки и ответы оператора — переслать в чат: по ним готовим API и проверку подписи на портале.
