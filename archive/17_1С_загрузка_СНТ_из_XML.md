# 17. 1С — кнопка «Загрузить СНТ из XML файлов» (электронные накладные на товары, выданные)

Статус: 🔄 в работе (поставлено 15.10.2026)

## Задача
В 1С КА для Казахстана 2.4 (prod_Aneskom_KA25) в списке «Электронные накладные на товары (выданные)» нужна кнопка
«Загрузить СНТ из XML файлов» — как кнопка «Загрузить ЭСФ из XML файлов» в списке «Электронные счета-фактуры (полученные)».

## Договорённости
- Поведение как у ЭСФ: выбираются один или несколько XML (выгрузка с портала ИС ЭСФ), по номеру/рег. номеру СНТ ищется документ в 1С:
  найден — обновляются рег. номер, дата, статус; не найден — создаётся новая СНТ.
- Реализация — расширением конфигурации (стандартный код не трогаем).
- **Сначала проверить в копии базы на сервере 172.16.125.199, потом в рабочей** (правило пользователя).
- Пример XML-файла СНТ пользователь пришлёт позже; до этого — по схеме СНТ ИС ЭСФ.

## План
- 📋 Посмотреть в конфигурации, есть ли штатная загрузка СНТ из XML (общие модули ЭлектронныеНакладныеНаТовары*, команда в списке «полученные»).
- 📋 Расширение: команда и кнопка на форме списка «ЭлектронныеНакладныеНаТоварыВыданные» → вызов штатного разбора XML либо свой разбор.
- 📋 Установить в копию базы, протестировать на реальном XML.
- ⏳ Пользователь проверяет в копии → перенос в рабочую базу.
