# 17. 1С — кнопка «Загрузить СНТ из XML файлов» (электронные накладные на товары, выданные)

Статус: 🔄 в работе (поставлено 15.10.2026)

## Задача
В 1С КА для Казахстана 2.4 (prod_Aneskom_KA25) в списке «Электронные накладные на товары (выданные)» нужна кнопка
«Загрузить СНТ из XML файлов» — как кнопка «Загрузить ЭСФ из XML файлов» в списке «Электронные счета-фактуры (полученные)».

## Договорённости
- Поведение как у ЭСФ: выбираются один или несколько XML (выгрузка с портала ИС ЭСФ), по номеру/рег. номеру СНТ ищется документ в 1С:
  найден — обновляются рег. номер, дата, статус; не найден — создаётся новая СНТ.
- Реализация — расширением конфигурации (стандартный код не трогаем).
- **Сначала проверить в копии базы на сервере 172.16.125.199, потом в рабочей** (правило пользователя).
- Пример XML-файла СНТ пользователь пришлёт позже; до этого — по схеме СНТ ИС ЭСФ.

## Ход работы 15.10 (вечер, копия базы «ANESCOM-KA 2024», \\LOGIKAL\Base\1C\KA)
- ✅ Разобрана типовая: документ «СНТ» один (направление — реквизит), список выданных — форма `ФормаСпискаИсходящих`. Штатной загрузки СНТ из XML нет (глобальный поиск — 0).
- ✅ Найдена экспортная функция обработки `ОбменСНТ`: `СоздатьОбновитьПолучаемыеСНТ(sntInfoList, Направление, СтруктурнаяЕдиница, УчитыватьВсеСтатусы, …)` — создаёт/обновляет документы из XDTO-объектов `sntInfo`. Статусы: NOT_VIEWED/DELIVERED/CONFIRMED/… (СНТКлиентСервер.СтатусСНТ_ИЗ). Структурная единица — из Справочник.ПрофилиИСЭСФ.СтруктурнаяЕдиница.
- ✅ Файл выгрузки с портала (export_snt.xml): `<snt:sntInfoContainer><sntInfoSet><sntInfo>…` — ровно формат API (sntId, status, registrationNumber, documentInfo/sntBody). Свой разбор не нужен: читать `sntInfo` XDTO-фабрикой `ФабрикаСНТ_XML_API_ВЦП_Версия1()` и передавать в типовую функцию.
- ✅ Создано расширение `ЗагрузкаСНТANESCOM` (префикс `ан_`, безопасный режим выкл.), в него добавлена форма `Документ.СНТ.ФормаСпискаИсходящих`.
- ℹ️ На форме есть «мёртвая» кнопка `Список.ЗагрузитьИзXML` без команды — заготовка 1С, без конфигуратора не оживить.
- 📋 Осталось: общий модуль `ан_ЗагрузкаСНТ` (сервер: временное хранилище → ЧтениеXML → XDTO sntInfo → СоздатьОбновитьПолучаемыеСНТ), команда+кнопка на форме (выбор файлов, НачатьПомещениеФайлов), обновить копию, тест на export_snt.xml, затем установка в рабочую базу через «Администрирование → Расширения».
